Courier Tracking API demo

Plain page mirroring docs/api-examples.md. Start the application with make run, then open http://localhost:8080/demo.html. Success cases only; each step shows the expected status and a green bar means the response matched it.

A fresh ID keeps each walkthrough independent; reusing an ID never resets its distance.
